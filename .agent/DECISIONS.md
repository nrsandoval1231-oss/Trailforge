# Decisions

This file records current governing decisions. Historical decision packets remain preserved under `.agent/artifacts` and Git history.

## 2026-10-01 — TrailForge commercial reset

- TrailForge's primary purpose is to prove early project signals that create measurable lead-time advantage for temporary/distributed-power pursuits.
- The primary research question is whether a signal could have surfaced a real project earlier using only evidence available at that historical time.
- Primary metric: lead-time advantage versus a verified conventional/obvious downstream milestone.
- Supporting metrics: project coverage, action burden, unresolved rate, evidence quality, and direct buyer-path availability at first surface.
- Next empirical target: approximately 20-50 source-backed historical power projects.
- Existing deterministic replay, temporal evidence, frozen ledger, provenance, experiment persistence, outcome sealing and local workbench are retained as useful infrastructure.
- Do not add governance or architecture merely to complete historical plans. Add complexity only when required by the experiment.
- TrailForge is the proving ground; GridLens is the intended live discovery/commercial surface for validated signals.
- Commercial ordering is fixed: signal -> project -> power-gap hypothesis -> direct customer/EPC/GC/electrical contractor -> conversation -> verified requirement -> generation/fuel strategy.
- Fuel providers are downstream fulfillment partners, not the default upstream lead source.
- Generic RFP aggregation is not the primary product because an obvious RFP is often already late relative to the desired discovery advantage.
- Historical artifacts must remain immutable evidence of prior work; current governing docs may supersede their old roadmap language without rewriting them.
- UNKNOWN remains explicit. No future evidence, invented project identity, unsupported MW, guessed buyer authority, fabricated dates, or fabricated outcomes.
