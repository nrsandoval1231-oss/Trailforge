# Trailforge Jade brand system

This package contains the Trailforge Jade identity, source design tokens, outlined logo masters, local fonts and licenses, and an offline interactive brandbook. Open `brandbook.html` directly in a browser; it does not require a server or network access.

**Identity approval:** The owner approved the Trailforge Jade logo and palette on 2026-10-03 (“love it lock it in! now full brand kit with color palette”). See [APPROVED_IDENTITY.json](APPROVED_IDENTITY.json) for the locked master hashes. The approved screen palette is Deep Jade `#126653`, Graphite `#232B26`, Warm Paper `#F5F4EE`, Mist `#EEF4EF`, Mint `#70D1AE`, and Brass `#B49A60`.

## Start here

- [Brandbook](brandbook.html) — identity, usage, voice, accessible states, and application examples.
- [Implementation guidelines](brand-guidelines.md) — production dimensions, color, typography, and constraints.
- [Token source](tokens.json) and [CSS tokens](tokens.css).
- [Approved color palette](exports/svg/color-palette.svg), [1600 px PNG](exports/png/color-palette-1600.png), and [palette data](palette/palette.json).
- `exports/svg/` — scalable masters and templates; `exports/png/` — transparent icon and horizontal previews plus white proof board.
- `fonts/` — local Manrope and IBM Plex Mono files with their OFL license texts.

Brand promise: source facts, buyer paths, human judgment. The identity does not claim forecast accuracy, verified customer intent, autonomous outreach, or comprehensive discovery. No trademark clearance is represented by this package.
