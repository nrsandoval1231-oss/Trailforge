# TrailForge — Canonical Product & Visual Direction
Owner-approved and locked October 29, 2026.

**Only product direction:** procurement intelligence centered on **Early, Active, Historical** opportunity boards. Detect RFPs/RFIs before solicitation, track source-confirmed open procurements and amendments, and preserve expired/awarded/canceled records as actionable buyer/rebid research. 'Discover early. Pursue intelligently. Learn from history.'

**Only visual direction:** [Canonical Brand System](../brand/CANONICAL_BRAND.md) and [UI Vision](UI_VISION.md), based on the final owner-approved Oct 29 mockup. Obsidian #171E1B, Forest #34483C, Brass #D7B77B, Limestone #F4F0E7, Copper #A76C4A. Copper angular mountain logo, Inter typography, full-width horizontal nav, warm limestone workspace, three equal home boards. NO LEFT SIDEBAR, NO JADE/TEAL/MINT/BRIGHT BLUE, no alternate visual direction.

**Authority order:** this vision + [PRD](PRD.md) for product; brand system + UI vision for visual specifics. Prior Jade brand files, mining-first UI, generic dark dashboards and alternate visual experiments are legacy and cannot override these. Historical research/engine code is retained for compatibility, not an alternate product strategy.

**Implementation honesty:** the current local Firecrawl Find and operator screens are older functionality. Do not claim the approved mockup is implemented until built and visually verified. Procurement type, stage and authoritative status remain separate. Unknown is not verified open.
