# TrailForge — Canonical UI Vision
LOCKED October 29, 2026. Visual authority: [brand system](../brand/CANONICAL_BRAND.md). Product authority: [PRD](PRD.md).

## Home screen
Reproduce the owner's approved three-board mockup. Obsidian top navigation and copper mountain logo; warm limestone hero 'RFPs. RFIs. Real Opportunities.' with four metrics; one compact filter row; **three equal columns** Early, Active, Historical. Each column has a richly toned mountain/terrain header and warm light opportunity list with status/type, buyer, location, value, dates, and full-board action. The home screen is not a four-board dashboard. Intelligence, Reports, Watchlist and search are destinations in the top navigation. No left rail, no generic dark dashboards, no teal/jade, no bright blue accents.

## Expanded workspaces
Early: upcoming notices, sources-sought, pre-solicitation and market engagement; never confuse with open bids.
Active: verified open RFIs/RFPs/RFQs/tenders, authoritative deadlines with timezones, changes, amendments, buyer and submission links.
Historical: expired, awarded, canceled, withdrawn and closed solicitations with full documents and issuer/rebid research.
One unified solicitation detail page: original official record, provenance, attachments, scope, amendments, deadlines, stage vs status, buyer contacts where proven, supplier fit, next action and history.

## UX constraints
Inter typography; colors only #171E1B Obsidian, #34483C Forest, #D7B77B Brass, #F4F0E7 Limestone, #A76C4A Copper for brand treatment. Limited semantic colors only when necessary. Subtle topographic imagery permitted in hero and board headers as in approved image. Mobile stacks boards. Dense readable rows, accessible focus, keyboard and responsive search/filters. No synthetic production metrics. Existing local app does not yet implement this design; preserve working workflows until migration.
