# Local UI Scope

The local workbench is an operator surface for TrailForge experiments. It is not the product objective.

## Current purpose

The UI should make historical lead-time experiments easy to run and understand:
- choose a project/case or cohort;
- inspect source/reviewer context;
- run deterministic time-bounded replay;
- see first surfaced date and evidence basis;
- inspect downstream comparison milestone;
- see lead-time advantage or explicit unresolved state;
- inspect buyer-path evidence available at signal time;
- save, recover and verify replay.

The existing GT-003 mechanics workflow remains valid regression coverage. New UI work should be driven by the historical-cohort experiment, not generic dashboard polish.

No hosted service, autonomous outreach, customer contact, or fuel-provider-first workflow is required.
