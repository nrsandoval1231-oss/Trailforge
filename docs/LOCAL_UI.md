# TrailForge Local Workbench

Run from the checkout:

`uv run --python 3.11 trailforge-ui`

Open the printed loopback URL.

The current workbench supports deterministic local experiment inspection/replay. Its next product role is to become the simplest operator surface for historical project/cohort experiments: understand what evidence was visible, when the policy first surfaced the project, the later comparison milestone, resulting lead-time advantage, and what direct buyer path was knowable then.

Until cohort support is implemented, use the existing case workflow as mechanics/regression coverage. Do not interpret UI success as proof of signal quality.

TrailForge remains local and research-oriented. Customer outreach and fuel-provider selection are downstream commercial activities, not UI execution authority.
