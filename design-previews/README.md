# Trailforge Jade UI preview

Owner-approved standalone design concept. Open `trailforge-ui-concept.html` in a browser. Jade is the default; Copper and Arctic remain selectable. The preview covers Projects, Discover, Buyer research, Conversations, Research Arena overview, project detail and sample intake.

All content is illustrative. Sample edits live only in page memory and reset on refresh. No live research, outbound messages, backend writes or customer data are involved. This does not replace the working application.

The full-preview browser pass checked all five routes at 320, 768 and 1280 pixels without horizontal overflow, plus sample intake/search/detail at 390 pixels. Draft saving, signal review, buyer notes, themes and motion controls were verified. Jade-default syntax and identity are validated again for this release. Reduced motion/transparency and opaque fallbacks are included.
